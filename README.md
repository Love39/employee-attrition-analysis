# employee-attrition-analysis
## Overview
This project analyzes employee attrition data to identify factors associated with employee turnover and provide recommendations to improve employee retention. 

## Tools Used
- Microsoft Excel
- Pivot Tables
- Data Visualization

## Key Findings
- Overall attrition rate: 16.12%
- Sales department recorded the highest rate of employee exits (20.63%)
- Laboratory Technicians experienced the highest turnover (62 employees)
- Employees working overtime showed higher attrition (53.59%)
- Attrition varied across job satisfaction levels

- Monitor employee overtime and workload
- Strengthen retention initiatives in high-turnover areas
- Improve employee engagement and satisfaction programs
